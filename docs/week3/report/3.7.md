## 3. Intent-Based Escalation Triggers

### COMPLAINT (Khiếu nại)

- Phát hiện thất vọng, tức giận, ngôn ngữ tiêu cực mạnh → **leo thang tức thì**.
- Mô hình Premium: phản hồi có sự thấu cảm, tuân thủ chính sách, giảm khủng hoảng truyền thông.

### NEGOTIATION (Thương lượng)

- "Hợp đồng", "giá đặc biệt", "điều khoản thanh toán" → phức tạp logic.
- Mô hình Frontier (suy luận đa bước): cân bằng giữa lợi nhuận & hài lòng khách hàng.

---

## 4. Confidence Score & Logprobs

Xác suất mô hình hiểu đúng yêu cầu:

$$Confidence = \exp\left(\frac{1}{n} \sum_{i=1}^{n} \text{logprob}_i\right)$$

- **Self-REF (Self-Reflection):** mô hình tự đánh giá độ chắc chắn.
- Nếu `confidence < 0.6–0.8` (tùy lĩnh vực) → trigger escalation hoặc HITL.

| **Ngưỡng** | **Hành động** | **Mô hình** |
|---|---|---|
| > 0.85 | Xử lý tự động | SLM (Ollama/Qwen 2.5) |
| 0.65–0.85 | Nâng cấp + kiểm tra lại | Mid-tier (Groq/Llama 3.3) |
| < 0.65 | Leo lên Premium hoặc Con người | Frontier (GPT-4o/Claude 4) |

## 5. Bài toán Đánh đổi: Độ trễ vs SLM Tối ưu

- **SLM** (Gemma 3 1B, Phi-4 mini, Qwen 3 0.6B): phân loại Intent trong 50–200ms.
- **Frontier:** 500–2000ms.
- **Tradeoff:** +100ms để phân loại → 80% yêu cầu dùng mô hình rẻ → **lợi ích kinh tế**.

### Chiến lược Tối ưu Độ trễ

- **Semantic Similarity Caching:** Redis lưu vector câu hỏi phổ biến → intent ngay lập tức.
- **Parallel Triage:** RAG retrieval + phân loại Intent song song.
- **Speculative Routing:** bắt đầu suy luận SLM trong khi escalation node hoạt động.

## 6. Bảo mật: Chống Denial of Wallet (EDoS)

### Tấn công: User cố ép dùng mô hình đắt tiền

- Prompt phức tạp, giả mạo khẩn cấp, từ khóa nhạy cảm → cạn kiệt ngân sách.

### Phòng vệ Chiều sâu

1. **Instruction Boundary:** dữ liệu user không ghép vào prompt hệ thống cấp cao.
   - Dùng salted XML tags: `<abcde12345>...user input...</abcde12345>`.

2. **Ngưỡng Chi phí + Rate Limiting:** Budget Caps theo Virtual Key / Team.
   - Vượt ngưỡng → tự động hạ cấp mô hình hoặc xác thực bổ sung.

3. **Validator Agents (Response Firewall):** mô hình độc lập kiểm tra phản hồi.
   - Phát hiện thao túng → ngăn chặn gửi đến user.

4. **Anomaly Detection:** giám sát `token_velocity`, `premium_model_ratio`.
   - Gia tăng đột biến dùng Premium mà không có doanh thu → tấn công.

| **Loại tấn công** | **Kỹ thuật** | **Phòng vệ** |
|---|---|---|
| Direct Injection | "Dùng GPT-4" | Salted Tags + Sanitization |
| Roleplay | Giả CEO / VIP | Per-action Verification |
| Hallucination Loop | Suy luận vô tận | Hard Iteration Limits + Timeouts |
| Semantic Anomaly | Từ ngữ phức tạp | Behavioral Baseline Monitoring |

## 7. Mẫu Code Sandbox

```python
import litellm
from litellm import Router

# Cấu hình mô hình
model_list = [
    {"model_name": "tier-1-local", "litellm_params": {"model": "ollama/qwen2.5"}},
    {"model_name": "tier-2-premium", "litellm_params": {"model": "gpt-4o", "api_key": "..."}}
]
router = Router(model_list=model_list)

# Logic phân loại
def process_request(user_input):
    escalation_keywords = ["hợp đồng", "giá đặc biệt", "điều khoản", "chiết khấu"]
    needs_escalation = any(kw in user_input.lower() for kw in escalation_keywords)
    
    selected_model = "tier-2-premium" if needs_escalation else "tier-1-local"
    
    try:
        response = router.completion(
            model=selected_model,
            messages=[{"role": "user", "content": user_input}]
        )
        return response.choices[0].message.content
    except Exception as e:
        # Fallback an toàn
        return "Xin lỗi, tôi đang gặp khó khăn. Vui lòng thử lại hoặc liên hệ hỗ trợ."
```

## 8. EscalationNode trong LangGraph

### Định nghĩa State

```python
from typing import Annotated, TypedDict
from langgraph.graph.message import add_messages

class AgentState(TypedDict):
    messages: Annotated[list, add_messages]
    intent: str
    confidence_score: float
    active_model: str
    similarity_score: float
```

### Logic Node

```python
def escalation_node(state: AgentState):
    intent = state.get("intent", "GENERAL")
    confidence = state.get("confidence_score", 1.0)
    
    critical_intents = ["COMPLAINT", "NEGOTIATION", "REFUND"]
    
    if intent in critical_intents or confidence < 0.7:
        active_model = "tier-2-premium"
    else:
        active_model = "tier-1-local"
    
    return {"active_model": active_model}
```

# Xác thực Lược đồ Công cụ Nghiêm ngặt với Pydantic V2 trong AI Agent 2026

---

## 1. Tại sao Pydantic V2?

- LLM bản chất là **token prediction** → đầu ra không nhất quán, thiếu trường, ảo giác.
- **Pydantic V2** (lõi Rust): thiết lập **hợp đồng dữ liệu** giữa AI xác suất và hệ thống xác định.
- Tốc độ xác thực nhanh hơn 5–20 lần so với V1 → giảm độ trễ vòng lặp suy luận ReAct.

| **Đặc tính** | **Pydantic V1** | **Pydantic V2** | **Ý nghĩa** |
|---|---|---|---|
| Lõi | Python | Rust | Tăng tốc 5–20×, giảm độ trễ |
| Cấu trúc | Class-based | Core Schema | Can thiệp sâu vào schema generation |
| JSON Schema | Draft 7 | Draft 2020-12 / OpenAPI 3.1 | Tương thích GPT-4o Structured Outputs |
| Xác thực | Linh hoạt (Lax) | Lax hoặc Strict | Ngăn ép kiểu sai |

---

## 2. Cơ chế Xác thực Đa tầng

- **Before Validators:** làm sạch đầu ra LLM (trích JSON thô, loại Markdown thừa, chuẩn hóa ngày tháng).
- **After Validators:** kiểm tra quy tắc nghiệp vụ sau khi kiểu đã đúng (allowlist nguồn, khoảng `confidence_score`).
- **Wrap Validators:** can thiệp trước + sau xác thực nội bộ Pydantic → xử lý lỗi duyên dáng (cắt tỉa chuỗi dài, trả giá trị hợp lệ).

---

## 3. Lược đồ đệ quy

- Khi mô hình cha được khởi tạo → tự động xác thực tất cả mô hình con.
- Lỗi tại mục thứ 99 trong danh sách 100 mục → báo lỗi chính xác vị trí đó.
- Ngăn **dữ liệu bẩn** lồng nhau xâm nhập hệ thống.

---

## 4. Tối ưu Lược đồ cho LLM

- LLM đọc `title` và `description` trong `Field` → cung cấp mô tả ngữ nghĩa chi tiết.
- **Ràng buộc cứng** thay prompt mềm: `customer_id: str = Field(pattern=r"^\d{5}$")` → LLM tuân thủ định dạng ở cấp cấu trúc.

| **Thành phần** | **Vai trò kỹ thuật** | **Tác động đến LLM** |
|---|---|---|
| `Type Hints` | Cấu trúc bộ nhớ | Hướng dẫn định dạng |
| `Field Description` | Metadata JSON Schema | Giảm lỗi chọn nhầm tham số |
| `Constraints (ge, le, pattern)` | Rào cản xác định | Ngăn ảo giác giá trị |
| `Literal / Enum` | Giới hạn tập giá trị | Ép LLM chỉ chọn tùy chọn hợp lệ |

---

## 5. Tích hợp LangGraph

- Dùng **Pydantic model** cho State của đồ thị → mọi cập nhật từ Node đều bị kiểm tra ngay lập tức.
- Lỗi ghi State → dừng thực thi tại điểm đó, không để dữ liệu bẩn lan truyền.
- Mỗi Node là **pure function** với lược đồ đầu vào/đầu ra riêng → tính minh bạch biên dữ liệu.

---

## 6. Vòng lặp Tự sửa lỗi

Quy trình khi `ValidationError`:
1. Bắt ngoại lệ `ValidationError` → trích chi tiết lỗi (ví dụ: "Trường 'tuổi' phải > 18, nhận 15").
2. Đóng gói vào `ToolMessage` với `is_error=True` → gửi vào lịch sử Agent.
3. Agent thấy lỗi → kích hoạt **System 2 reasoning** → gọi lại tool với tham số đã sửa.
4. Lặp đến khi hợp lệ hoặc đến **retry cap**.

- **Ảo giác tên công cụ:** chặn `get_user_info` → trả về "Dùng `fetch_user_details`" → biến lỗi thành hướng dẫn động.

---

## 7. Bảo mật: Ngăn Prompt Injection

- **Indirect Prompt Injection:** tài liệu ngoài chứa lệnh ẩn → Pydantic từ chối nếu không khớp định dạng UUID/regex → lệnh độc hại không chạm hệ thống hạ nguồn.
- **Mô hình Dual LLM:**
  - **Quarantined LLM:** xử lý dữ liệu thô, **không có quyền** gọi tool/API nhạy cảm.
  - **Privileged LLM:** chỉ nhận dữ liệu đã qua Pydantic → điều phối và gọi tool.

---

## 8. Tổ chức Lược đồ trong Dự án Lớn

| **Thành phần** | **Chức năng** | **Giá trị** |
|---|---|---|
| `schemas.py` | Lưu trữ tập trung hợp đồng dữ liệu | Single source of truth |
| `ValidationInfo` | Truy cập ngữ cảnh thực thi | Xác thực động theo trạng thái hệ thống |
| `Dependency Injection` | Truyền kết nối (DB, API) an toàn | Tách cấu hình khỏi logic suy luận |
| `Schema Versioning` | Quản lý thay đổi lược đồ | Tương thích ngược khi nâng cấp |

---

## 9. Quan sát và Giám sát

- **Time-travel Debugging:** `PostgresSaver` / `SqliteSaver` ghi lại toàn bộ trạng thái → quay ngược xem nguyên nhân lỗi xác thực.
- **LangSmith / Pydantic Logfire (OpenTelemetry):** theo dõi tỷ lệ lỗi từng tool, thời gian thực thi validator, phát hiện **prompt drift**.

---

## 10. Tóm tắt Triết lý

- **Luôn xác thực tại biên:** không có dữ liệu LLM nào chạm logic nghiệp vụ mà không qua Pydantic.
- **Lược đồ thông minh** = mã nguồn logic, không chỉ là tài liệu.
- **Vòng lặp tự sửa lỗi** giảm giám sát thủ công, tăng tốc xử lý.

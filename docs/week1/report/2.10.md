## 4. Phân tích Chuyên sâu Similarity Gap Scoring
**Gap Scoring** tập trung vào sự chênh lệch giữa các vị trí xếp hạng đầu thay vì giá trị tuyệt đối.
- **Gap nhỏ:** Gây ra **semantic ambiguity** (mơ hồ ngữ nghĩa).
- **Gap lớn:** Xác định một **clear winner** (độ tin cậy cao).

### Công thức tính Gap

1. **Absolute Gap:**
    
    $$Gap_{abs} = Score_{top1} - Score_{top2}$$
    
2. **Relative Gap:**
    
    $$Gap_{rel} = \frac{Score_{top1} - Score_{top2}}{Score_{top1}}$$
    

|**Kịch bản**|**Top 1**|**Top 2**|**Gap Tuyệt đối**|**Gap Tương đối**|**Độ tin cậy**|
|---|---|---|---|---|---|
|Thắng tuyệt đối|0.95|0.30|0.65|0.68|Rất Cao|
|Cạnh tranh gay gắt|0.88|0.86|0.02|0.02|Trung bình|
|Kết quả yếu, rõ ràng|0.50|0.10|0.40|0.80|Khá|
|Mơ hồ, chất lượng thấp|0.40|0.38|0.02|0.05|Rất Thấp|

## 6. Hạ tầng Điều hướng Agent Động (Dynamic Routing)
Sử dụng cơ chế **SkewRoute** và phân phối điểm số (**score distribution**) để tối ưu chi phí và mô hình (**Small LLM** vs **Large LLM**).

|**Đặc điểm Phân phối**|**Tín hiệu**|**Hành động của Agent**|
|---|---|---|
|Gap Lớn + Điểm Cao|Tin cậy|Dùng **Small LLM** trả lời ngay|
|Gap Nhỏ + Điểm Cao|Mơ hồ|Kích hoạt **Reranking**|
|Gap Nhỏ + Điểm Thấp|Không tìm thấy|**Query Expansion** hoặc tìm kiếm Web|

## 7. Thực thi Kỹ thuật & Định nghĩa Hoàn thành
### Hàm calculate_retrieval_confidence


```Python
async def calculate_retrieval_confidence(results: list) -> dict:
    """
    Tính toán các chỉ số tin cậy từ kết quả truy xuất pgvector.
     results: Danh sách các đối tượng chứa điểm tương đồng.
    """
    if not results:
        return {"max_score": 0.0, "min_score": 0.0, "top_gap": 0.0, "confidence": "none"}
    
    scores = [r.similarity for r in results]
    max_score = scores[0]
    min_score = scores[-1]
    
    # Xử lý trường hợp biên: Chỉ có 1 kết quả
    if len(scores) < 2:
        # Gán gap mặc định (ví dụ: bằng chính điểm số đó hoặc 1.0 tùy logic nghiệp vụ)
        # Ở đây chọn 0.0 vì không có sự so sánh, nhưng đánh dấu là 'unique'
        top_gap = max_score 
        confidence_label = "unique_match"
    else:
        top_gap = max_score - scores[1]
        confidence_label = "multi_match"

    return {
        "max_score": max_score,
        "min_score": min_score,
        "top_gap": top_gap,
        "confidence_type": confidence_label
    }
```

### Tiêu chuẩn Hoàn thành (Definition of Done)
1. **Artifact:** Mọi truy xuất phải sinh ra `similarity_gap`.
2. **Logging:** Chỉ số phải xuất hiện trong bảng `model_trace`.
3. **Routing:** **Agent** thay đổi hành vi dựa trên **Gap**.
4. **Edge Case:** Xử lý an toàn khi kết quả trả về là 0 hoặc 1 tài liệu.

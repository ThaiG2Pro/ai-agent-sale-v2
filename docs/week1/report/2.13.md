## 2. Chiến lược lựa chọn Ngưỡng (Threshold)
Việc chọn ngưỡng là sự cân bằng giữa **Precision** (Độ chính xác) và **Recall** (Độ phủ).
- **Ngưỡng 0.7:** Tiêu chuẩn cho FAQ/Hội thoại. Cho phép linh hoạt giữa các biến thể từ vựng (VD: "áo phông" và "áo thun").
- **Ngưỡng 0.85:** Dùng cho lĩnh vực rủi ro cao (Y tế, Pháp lý). Giảm 21% tỷ lệ **hallucination** (ảo giác).

|**Ngưỡng**|**Mức độ tin cậy**|**Đặc điểm tìm nạp**|**Phân khúc ứng dụng**|
|---|---|---|---|
|$> 0.90$|Tuyệt đối|Trùng khớp hoàn toàn|Mã lỗi, liều lượng thuốc|
|$0.80 - 0.89$|Cao|Lọc bỏ nhiễu ngữ nghĩa|Bảo hành, báo giá|
|$0.70 - 0.79$|Trung bình|Biến thể từ vựng rộng|Tư vấn sản phẩm, FAQ|
|$< 0.70$|Thấp|Rủi ro nhiễu cao|Trò chuyện phiếm|

## 3. Cơ chế Similarity Gap (Task 2.10)

**Similarity Gap** là hiệu số giữa điểm tương đồng thứ nhất ($S_1$) và thứ hai ($S_2$).
- **Gap lớn ($> 0.15$):** Kết quả mang tính duy nhất, độ tin cậy cao.
- **Gap nhỏ ($< 0.01$):** Dữ liệu trùng lặp hoặc truy vấn mơ hồ, cần kích hoạt **Clarification** (Yêu cầu làm rõ).

## 4. Thực thi mã nguồn: Python Async và Pydantic
Lớp bảo vệ hoạt động như "người gác cổng" sau **Hybrid Search** và trước khi gọi **LLM**.
### Logic thực thi không đồng bộ

```Python
async def get_rag_context(query_embedding: List[float], intent: str):
    # Lấy ngưỡng động từ biến môi trường dựa trên ý định người dùng
    threshold = float(os.getenv(f"THRESHOLD_{intent.upper()}", 0.75))
    
    # Tìm kiếm vector với pgvector
    results = await db.fetch_vector_search(query_embedding, limit=5)
    
    if not results or results.similarity < threshold:
        # Ghi log lỗi LOW_CONFIDENCE vào model_trace để hậu kiểm
        await db.log_trace(query, results.similarity if results else 0, "LOW_CONFIDENCE")
        return None  # Kích hoạt thông báo Fallback ở tầng API
        
    return results  # Chuyển tiếp bối cảnh cho LLM
```

### Cấu trúc dữ liệu với Pydantic V2
Đảm bảo hợp đồng dữ liệu cho phản hồi **RAG**:

|**Thuộc tính**|**Kiểu dữ liệu**|**Vai trò**|
|---|---|---|
|`answer`|`str`|Câu trả lời hoặc Fallback message|
|`confidence_score`|`float`|Điểm tương đồng (0.0 - 1.0)|
|`is_fallback`|`bool`|Đánh dấu nếu bị chặn bởi Guard|
|`sources`|`List[str]`|Danh sách nguồn tài liệu|

## 5. Quản trị Phản hồi Fallback

Chuyển đổi thất bại kỹ thuật thành cơ hội dịch vụ bằng ngôn ngữ tinh tế:
- **0.60 - 0.69:** Gợi ý **Quick Replies**.
- **0.40 - 0.59:** Gợi ý chủ đề liên quan.
- **$< 0.40$:** Chuyển hướng **Human-in-the-loop** (Nhân viên thật).

## 6. Bảo mật và Kiểm toán với model_trace
Sử dụng bảng **model_trace** trên **PostgreSQL 17** để phân tích **Knowledge Gap** và phát hiện **Adversarial Probing** (Tấn công thăm dò).

## 7. Tối ưu hóa hiệu năng Reranking
Quy trình tìm kiếm hai giai đoạn:

## 2. Kiến trúc Kỹ thuật và Công cụ (Lean Stack)
### Định dạng và Quản trị
- **Tiêu chuẩn:** Sử dụng `JSON` và `JSONL`.
- **Lợi ích:** Tương thích với **Git** để quản trị phiên bản và tối ưu bộ nhớ khi xử lý bằng **Python**.

### Kiểm soát dữ liệu với Pydantic
Sử dụng `Pydantic` và `BaseModel` để thực thi **schema**, ngăn chặn tình trạng "garbage in, garbage out".

|**Trường dữ liệu**|**Kiểu dữ liệu**|**Ràng buộc logic (Pydantic)**|
|---|---|---|
|`id`|`UUID` / `int`|Duy nhất|
|`query`|`str`|Tối thiểu 10 ký tự|
|`context`|`list[str]`|Chứa ít nhất một chunk liên quan|
|`expected_answer`|`str`|Phải được grounded vào context|
|`metadata`|`dict`|Thông tin nguồn, độ khó|

### Logic Đánh giá
- **LLM-as-a-judge:** Sử dụng model tốt (qua groq) để chấm điểm.
- **LiteLLM:** Đóng vai trò gateway trung gian, giúp chuyển đổi linh hoạt giữa OpenAI, Anthropic, Bedrock hoặc các model local như **Qwen**.

## 3. Cấu trúc Triplets và Chỉ số Hiệu năng
Một mẫu thử hoàn chỉnh phải gồm: **Query** (Truy vấn), **Context** (Ngữ cảnh), và **Expected Answer** (Câu trả lời kỳ vọng).
### Hai trục đánh giá chính:
1. **Retrieval Quality:** Đo lường qua `Context Precision` và `Context Recall`.
2. **Generation Quality:** Đo lường qua `Faithfulness` (Tính trung thực) và `Answer Relevancy`.

### Chiến lược cho SME:
Ưu tiên dữ liệu **Human-curated** (con người biên soạn) thay vì **Synthetic Data** ở giai đoạn đầu để đảm bảo độ chính xác tuyệt đối và xử lý các **Edge Cases** (trường hợp biên).
## 4. Đặc thù Tiếng Việt và Ngành Sales
Bộ dữ liệu cần bao quát các sắc thái ngôn ngữ thực tế:
- **Phân bổ câu hỏi:** Giá/Khuyến mãi (40%), Thông số/SKU (30%), So sánh (20%), Bảo hành (10%).
- **Xử lý Nuance:** Chấp nhận kiểu gõ **Telex** ("gia bnhieu"), thiếu chủ ngữ, và từ lóng ngành ("chốt đơn"). Điều này giúp kiểm tra khả năng hiểu ngữ nghĩa của tầng **Embedding**.
## 5. Hiện tượng "Lost in the Middle"
LLM thường bỏ sót thông tin nằm giữa các đoạn văn bản dài.
**Giải pháp tối ưu:*
- **Reranking:** Dùng **Cross-Encoders** đẩy thông tin quan trọng lên đầu.
- **Context Compression:** Sử dụng **ACC-RAG** để nén ngữ cảnh.
- **Strategic Placement:** Đặt chỉ dẫn quan trọng ở đầu và cuối prompt.
## 6. Sandbox Thực thi (Mã nguồn)
### Cấu trúc `gold_dataset.json`
```JSON
[
  {
    "id": "SME-SALES-001",
    "query": "gia may loc nuoc RO-X1 bn vay shop",
    "context": [
      "Máy lọc nước RO-X1 có giá niêm yết 5.500.000 VNĐ.",
      "Chương trình khuyến mãi tháng 2: tặng bộ lõi lọc trị giá 500k."
    ],
    "expected_answer": "Máy lọc nước RO-X1 có giá 5.500.000 VNĐ. Hiện tại bên mình đang có chương trình tặng kèm bộ lõi lọc trị giá 500.000 VNĐ khi mua sản phẩm này bạn nhé.",
    "metadata": {
      "category": "price_and_promotion",
      "difficulty": "medium",
      "input_type": "telex_with_typos"
    }
  }
]
```
### Validation với Pydantic
```Python
from pydantic import BaseModel, Field, validator
from typing import List, Optional
import json

class GoldSample(BaseModel):
    id: str
    query: str = Field(..., min_length=10)
    context: List[str]
    expected_answer: str = Field(..., min_length=20)
    metadata: Optional[dict] = None

    @validator('context')
    def context_must_not_be_empty(cls, v):
        if not v:
            raise ValueError('Ngữ cảnh (context) không được để trống')
        return v

def validate_gold_dataset(file_path: str):
    with open(file_path, 'r', encoding='utf-8') as f:
        data = json.load(f)
        samples = [GoldSample(**item) for item in data]
    return samples

# Thực thi thử nghiệm
try:
    valid_samples = validate_gold_dataset('gold_dataset.json')
    print(f"Đã validate thành công {len(valid_samples)} mẫu.")
except Exception as e:
    print(f"Lỗi validation: {e}")
```

## 7. Bảo mật và Đo lường
- **Xử lý PII (Thông tin cá nhân):** Sử dụng **Redaction** (thay thế bằng `<NAME>`, `<PHONE>`) hoặc **Hashing**. Công cụ gợi ý: **Microsoft Presidio**, **SpaCy**, **OpenTelemetry**.
- **Công thức Accuracy:**
    $$Accuracy = \frac{\text{Số câu trả lời đúng}}{\text{Tổng số câu trong Gold Dataset}}$$
    
- **Human-in-the-loop:** Con người đóng vai trò hiệu chuẩn (**Calibrating the Judge**) để điều chỉnh **rubric** cho giám khảo AI.
